# Document Intelligence

AI-powered general-purpose document extraction and understanding system.

## Features

- PDF and image document upload
- Text extraction using PyMuPDF
- OCR using PaddleOCR
- AI-based document understanding
- Document summary
- Entity and information extraction
- Highlight and annotation detection
- Raw extracted text preservation
- Downloadable analysis results

## Current Workflow

Upload Document

Text Extraction

Document Understanding

User chooses whether to analyze markings

Marking Detection

## Supported Files

- PDF
- JPG
- JPEG
- PNG
